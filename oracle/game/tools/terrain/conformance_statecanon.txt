# The fourteenth game-layer vertical slice and D24 §2's ASSEMBLED-STATE rung. Every rung before it earned an
# identity for ONE component of a run: `gamegen.level_digest` (world), `entity.entity_digest` (entity),
# `rngstream.stream_digest` (RNG state), `actionlog.digest` (ordered action history). This rung earns EXACTLY
# ONE new authority -- the single canonical identity `D_n` of the assembled run -- by COMPOSING those four

# THE LAW (one content-addressed digest over the four component identities):
#   D_n = SHA-256( MAGIC | lvl:<level_digest> | ent:<entity_digest> | rng:<stream_digest> | log:<actionlog digest> )
# Each component enters ONLY through its own authority's identity function, under a fixed label, delimited by
# the reserved `|`. Every component identity is 64 hex chars and contains no `|`, so the labelled, fixed-width,
# delimiter-framed preimage is injective in the four identities. `D_n` is the one and only new SHA-256 minted.

# THE ACTION HISTORY IS PART OF THE IDENTITY (the ratified choice): `D_n` includes `actionlog.digest`, so two
# runs at the SAME (level, entity, stream) reached by DIFFERENT histories have DIFFERENT `D_n` -- it identifies
# the run AND how it arrived. SEED/DEPTH ARE NOT SEPARATE COMPONENTS: `gamegen.level_digest` already commits to
# both (its canon bytes open `URDRGEN1|s:<seed>|d:<depth>|...`) and the seed re-enters via the RNG root, so a
# raw `seed` field would be redundant and is deliberately absent.
#
# THE AUTHORITY/VIEW BOUNDARY holds by construction at the seam this rung composes: a view-only quantity
# (facing/camera/interp) cannot enter `entity` (`FIELDS == ("pos",)` refuses any undeclared field), so it can
# never reach `entity_digest` and therefore never reach `D_n`.
#
# OWNERSHIP STAYS CRISP -- none of the three neighbouring laws absorbs another. `savegame` answers "can I
# restore this artifact?" (stores components independently, mints no assembled identity); `rerun` answers
# "does this recovered history reproduce the independently stored state?" (a REPRODUCED/DIVERGED verdict);
# `statecanon` answers "what is the canonical identity of this assembled state-and-history?" (a single digest).
# It exposes no serialize/restore/address (savegame's) and no replay/verdict/reconstruct_origin (rerun's), and
# imports neither module.
#

# all four component-identity authorities, mints EXACTLY ONE `sha256`, reaches none of the components' raw

# that reproduced the same `D_n` while BYPASSING an authority (inlining a component's own `sha256(preimage)`,

# `lockstep.canon`'s (tick, peer, seq) is Slice A), so it imports no `lockstep`.
