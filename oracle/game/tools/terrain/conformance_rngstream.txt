# actions" -- and its digest participates in canonical state identity, which is why a stateless draw

# ONE STREAM, ROOTED AT THE RUN'S SEED, DOMAIN-SEPARATED. R_0 = SHA-256(b"rngstream/v1"|b"|s:"|seed),
# the same `seed` `gamegen` uses, through a domain tag so it is not a `gamegen` derivation of that seed.

# tag-separated -- `adv` for the chain, `draw` for `peek` -- so a consumer's draw cannot collide with
