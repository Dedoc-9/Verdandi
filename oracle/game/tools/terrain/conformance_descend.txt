# URDRDEP1 conformance -- THE AUTHORITATIVE DEPTH TRANSITION: FROM THE DOWN-STAIRS TO THE NEXT FLOOR.
#
# The sixth game-layer vertical slice. `gamegen` makes one level from (seed, depth); `descent` witnesses
# its stairs connect; `move` steps within a level; `entity` names it; `rngstream` holds the stream. None
# CHANGES DEPTH. This is the single authoritative D_n -> D_{n+1} that advances it: an entity on the
# down-stairs of the level at depth d arrives at the level at depth d+1, at that level's own stairs-up.
#
# IT CONSUMES AUTHORITY IT DOES NOT OWN. DEPTH is `gamegen`'s: the bound, the admission of d+1 and the
# ceiling refusal are all `gamegen.check_params`, ASKED before anything is generated, and this module
# names no DEPTH_MAX of its own (checked on its AST). THE SUCCESSOR LEVEL is `gamegen.generate(seed, d+1)`,
# same seed, identity unchanged. THE STAIRS are `descent.endpoints` -- the unique down-stairs (precondition)
# and the successor's unique up-stairs (arrival). THE ARRIVAL POSITION is the successor's authoritative
# SPAWN, `descent.endpoints(level').up` == `move.spawn(level')`, traversable by construction and NOT
# re-proved here. THE ONE NEW THING is the depth transition and its single precondition: descend only from
# the down-stairs. `DESCEND-REFUSE` iff the supplied position is not the level's unique down endpoint.
#
# WHY THE OLD POSITION HAS NO AUTHORITY IN THE NEW LEVEL. The successor's layout is generated
# INDEPENDENTLY from (seed, d+1), so the old down-stairs coordinate is not reliably traversable there
# (measured: a wall in some successors). The only authoritative successor position is the new stairs-up.
#
# OWNERSHIP STAYS CRISP: malformed/invalid level -> descent/gamegen; invalid command -> move; blocked
# movement -> move (never an arrival on the down-stairs); depth ceiling (d = DEPTH_MAX) -> gamegen
# (GAMEGEN-REFUSE, inherited); valid arrival on the down-stairs -> descend; descend off the down-stairs
# -> descend (DESCEND-REFUSE). RNG IS UNTOUCHED: the successor is fully determined by (seed, d+1), descend
# never receives or returns a stream and imports no `rngstream`, read off its AST.
#
# The `transition` scene pins, per corpus member with depth < DEPTH_MAX, the successor depth, its stairs-up
# and the successor's canonical state identity in the ONE existing (level, entity) vocabulary
# (`move.state_digest`); the `boundary` scene pins the DEPTH_MAX-1 positive witness and, per DEPTH_MAX
# member, the ceiling refusal ordering (refused GAMEGEN-REFUSE, input unchanged, no DEPTH_MAX literal); the
# `laws` scene pins the spawn/reproduces/off-stairs/malformed/no-rng/refuse booleans. All three and the top
# digest are what the module EMITS and stay FROZEN, because a golden the gate rewrites cannot detect drift.
#
