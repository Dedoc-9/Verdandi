# URDRGEN1 conformance -- SEED + DEPTH -> CANONICAL LEVEL -> DIGEST, AND NOTHING ELSE.
#
# The first game-layer vertical slice, and the first module admitted under D24. D24 §1 asks: does
# this affect canonical game state, or is it a view of it? This module affects canonical game state.
# It is CORE; it imports `hashlib` and `os` and nothing under tools/; it renders nothing and needs
# no window, clock, input device or audio. The contract was written first (docs/gamegen_brief.md
# §1) and the module was held to it.
#
# THE CONTRACT. Input: (seed, depth), 0 <= seed < 2**64, 1 <= depth <= DEPTH_MAX, anything else a
# typed GAMEGEN-REFUSE. Output: a fixed 48 x 32 grid over `# . < >` plus the rooms, SORTED.
# Identity: URDRGEN1|s:|d:|48x32|rooms:...|row|...|row -- nothing else enters. Digest: SHA-256 of
# the identity bytes, REPRODUCIBILITY ONLY and never the correctness oracle.
#
# DEPTH IS THREE CLAIMS, KEPT APART. Representation: DEPTH_MAX is computed from the width and held
# equal to the literal 2147483647. Admission: 0 and DEPTH_MAX + 1 refuse, DEPTH_MAX is admitted.
# Generation: two DEPTH_MAX members are in the corpus below, pinned raw, well-formed, eight rooms
# each, at the same number of draws as depth 1. The question the original never asked -- does the
# deepest level generate? -- is answered for this generator by running it.
#
# THE DRAW IS STATELESS, in heightfield's idiom: SHA-256(MAGIC | seed | depth | tag | i), so no
# evaluation order can reach the output. MEASURED: over 128 seeds at depth 1 and 16 at DEPTH_MAX,
# every level generated, none refused, none malformed, and every one kept exactly ROOMS_MAX = 8
# rooms -- the admission condition (fewer than ROOMS_MIN kept) is REAL, demonstrated by a one-try
# plant that refuses typed, and NEVER MET in the sweep. Both facts are reported; neither is assumed.
#
# THE DIGEST IS NOT THE ORACLE. Structure has its own predicates and each has a PLANTED violation
# caught BY NAME: a breached border, an overlapping room, a second stairs up, a stairs in no room, a
# room hanging off the grid, an unsorted room list. Alongside them, two identity plants: reversing
# the room order before serialisation is INERT (declared inert, because identity sorts the rooms),
# and moving one wall cell is observable. And heightfield's corpus law: a generator with the
# opposite corridor bend moves EVERY one of the eight pinned digests.
#
# The eight `level-<seed>-<depth>` lines are RAW level digests, pinned so that a second
# implementation can match one level without reproducing a scene. None has, and none is claimed.
#
# does_not_show: that a level is worth playing; that the stairs down are reachable from the stairs
# up -- the corridors join consecutive rooms, so by construction they are, and CONSTRUCTION IS NOT A
# WITNESS; that the draw is unbiased (it is draw mod n, declared); that 48 x 32, eight rooms and an
# L-shaped corridor are the right constants -- each is a constant of this canon; and nothing about
# canonical GAME STATE, this being one level and not a run.
